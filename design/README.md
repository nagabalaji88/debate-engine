# UX concept studies

`ux-concepts.html` — a self-contained concept deck presenting six layout options for the
AI Debate & Decision Engine, all rendering the same worked example (five models, one
independent judge, outcome `MAJORITY_WITH_DISSENT` at 84% confidence).

| # | Concept | Covers |
|---|---------|--------|
| A | Control Room — three-pane console | Screens 1–4, Model Arena |
| B | Docket — decision as a written opinion | Screen 5 (and 4 via claim citations) |
| C | Claim Board — columns + alignment matrix | Screen 4, Model Arena |
| D | Focus Flow — mobile-first, one thing per screen | Screens 1, 2, 3, 5 |
| E | Workbench — split-pane Build Studio | Screen 6 |
| F | Ledger — dense history table | Debate History |

Plus a shared component kit (outcome badges, evidence chips, confidence meter, claim card,
position verbs, cost ticker) and a build recommendation for the 3–4 week MVP.

Design studies only: static HTML, no product code, no dependencies. Content is illustrative.
Open the file directly in a browser.
